# 회사에서 탈출하기

신입사원이 회사 건물을 한 층씩 내려가 1층 로비로 퇴근하는 도트 로그라이크.

**[플레이하기](https://minlabnote.com/exit-company/)**

- 턴제 칸 이동. 한 칸 움직이면 적도 한 칸 움직인다
- 층마다 맵이 새로 만들어진다
- 계단은 언제든 내려갈 수 있다. 그 층의 적을 모두 퇴근시키면 강화를 하나 더 받는다. 1층 로비 문은 적을 모두 퇴근시켜야 열린다
- 5층 18:00 부터 시계가 흐른다 (75턴마다 30분, 00:00 에서 멈춤)
- 계단을 내려갈 때마다 강화 두 장 중 하나를 고른다 (같은 강화를 또 받을 수 있다). 대신 아래층일수록 적 체력이 조금씩 오른다
- 멘탈이 0 이 되면 처음부터
- 한 판에 한 장까지 맵 어딘가에 일기 쪽지("어느 사원의 일기")가 떨어져 있다. 주우면 게임이 멈추고 종이에 적힌 일기가 뜬다 (아직 안 모은 장 중에서 무작위, 다 모으면 안 나온다. 월급 · 점수와는 상관없다). 지금은 1탄에만 있다

## 탄

| 탄 | 무대 | 체력 이름 | 열리는 조건 |
|---|---|---|---|
| 1탄 | 회사. 5F → 1F 로비로 퇴근 (18:00 부터) | 멘탈 | 처음부터 |
| 2탄 | 집. 현관 → 거실 → 부엌 → 침실 침대에 눕기 (21:00 부터) | 의지 | 1탄을 한 번 깨면 |
| 3탄 | 회식 | 미정 | 준비 중 |

규칙은 탄끼리 같고, 적 · 아이템 · 강화 · 가구 · 문구가 다르다. 2탄의 유혹: 숏폼 · 배달 앱 · 넷플릭스 · 술 · 보스 새벽 2시의 알고리즘.
주소 끝에 `?unlock` 을 붙이면 조건 없이 모든 탄이 열린다 (만드는 중에 바로 해 보는 용도).

## 시작화면

- **퇴근하기**: 탄을 고른다. 고르면 짧은 연출 뒤에 시작한다 — 1탄은 자리에서 일어나 걸어 나가고, 2탄은 21:00 현관문을 열고 들어온다 (아무 키·터치로 건너뜀, 움직임 줄이기를 켠 기기에선 생략)
- **상점**: 옷을 사고 갈아입는다. 판이 끝나면 퇴근시킨 적 수 + 모은 아이템 수만큼 월급이 통장에 들어온다. 옷은 모양만 바뀌고 능력치는 없다. 따로 고르지 않으면 탄에 맞는 옷을 입는다 (1탄 셔츠 · 2탄 잠옷) (이 기기에 저장)
- **게임 방법**: 목표 · 공격 방법 · 아이템 쓰는 법 (짧게)
- **도감**: 퇴근시킨 적 · 먹은 아이템과 그 횟수, 모은 일기. 못 만난 칸은 실루엣, 못 모은 일기는 ??? (이 기기에 저장)
- **기록**: 탄마다 따로 (위의 탄 단추로 바꿔 본다). 출근 · 퇴근 성공 횟수, 최고 점수, 가장 이른 퇴근 시각, 가장 빠른 퇴근(턴), 가장 멀리 간 곳, 최근 5판. 2탄은 귀가 · 취침으로 바꿔 부른다 (이 기기에 저장)
- **환경설정**: 효과음 볼륨, 멘탈 경보 켜기/끄기 (이 기기에 저장)

## 조작

| PC | 폰 | 하는 일 |
|---|---|---|
| 방향키 / WASD | 화면 아래 방향 패드 | 이동 · 적 쪽으로 이동하면 공격 |

| 1 · 2 · 3 | 아이템 버튼 | 커피 · 연차 · 반차 |

## 등장인물

| | 하는 짓 |
|---|---|
| 일 못하는 동기 | 쫓아와서 때린다 |
| 요구가 많은 고객사 | 한 줄로 보이면 멀리서 서류를 던진다 |
| 회식 좋아하는 팀장님 | 붙잡는다. 연차·반차로 빠져나온다 |
| 능력없는 상사 | 헤드폰 끼고 돌아다니다 가까이 가면 사람을 부른다. 쓰러지면 일을 떠넘겨 남은 적이 세진다. 4층부터 나온다 |
| 야근 강요하는 사장님 | 1층 출구를 막고 있다. 동기를 불러오고, 알아챈 뒤로 시계를 빨리 돌린다. 체력이 반 남으면 넥타이를 풀고 매 턴 움직인다 |

그림은 전부 코드로 그린 도트다. 효과음도 Web Audio 로 그 자리에서 합성한다. 외부 이미지·폰트·사운드 파일은 쓰지 않는다.

## 파일 구성

빌드 도구 없이 일반 `<script>` 로 불러온다. `index.html` 을 더블클릭해도 열린다.
파일끼리 전역을 공유하므로 **`index.html` 의 불러오는 순서를 바꾸지 않는다** (`ui.js` 가 마지막에 게임을 시작한다).

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인 |
| `js/sprites.js` | 도트 그림 데이터 |
| `js/data.js` | 1탄 회사: 수치 · 적 · 아이템 · 강화 · 시계 · 문구 (`COMPANY`), 탄 목록(`STAGES`) — 1탄 밸런스 조정은 여기서만 |
| `js/home.js` | 2탄 집: 같은 모양의 표 (`HOME`) — 2탄 밸런스 조정은 여기서만 |
| `js/map.js` | 칸 종류(`TILES`) · 층 자동 생성 |
| `js/sound.js` | 효과음 (걸음 · 현관문 · 쪽지 · 공격 · 던지기 · 맞음 · 아이템 · 정수기 · 강화 · 계단 · 멘탈 붕괴) + 멘탈 위험 경보 |
| `js/game.js` | 게임 상태 · 턴 처리 · 전투 · 결과 |
| `js/render.js` | 그리기 |
| `js/ui.js` | 입력 · 시작화면 · 메뉴얼 |
| `dev/compare-bot.js` | 구조를 바꿀 때 전후 비교용 봇 (게임에는 불러오지 않는다) |

## 내용을 늘릴 때 고치는 곳

게임 규칙 코드(`game.js`)에는 적 · 아이템 이름이 나오지 않는다. 표만 고치면 화면이 따라온다.

| 늘릴 것 | 고치는 곳 |
|---|---|
| 아이템 | `data.js` 의 `ITEM_TYPES` 한 덩어리 + `sprites.js` 의 그림 (`SPRITES[종류]`). 버튼 · 단축키 · 가방 · 도감은 자동 |
| 적 | `data.js` 의 `ENEMY_TYPES` 한 덩어리 + `ENEMIES_PER_FLOOR` 에 몇 층에 몇 명 + 그림. 행동은 `ai` 로 기존 것을 고른다 |
| 옷 | `data.js` 의 `OUTFITS` 한 줄 (이름 · 값 · 색). 상점에 자동으로 나온다 |
| 일기 | `data.js` 의 `COMPANY_DIARY.pages` 에 한 줄. 다른 탄에 넣으려면 같은 모양의 묶음을 만들어 탄 묶음의 `diary` 에 둔다. 쪽지 · 종이 화면 · 도감은 자동 |
| 새 행동 방식 | `game.js` 의 `ENEMY_AI` 에 한 줄 + 함수 하나 |
| 가구 · 칸 | `map.js` 의 `TILES` 한 줄 + 그림. 어떤 가구를 놓을지는 탄 묶음의 `map` |
| 탄 | `js/home.js` 처럼 파일을 하나 만들어 `HOME` 같은 묶음을 `STAGES` 에 넣고, `index.html` 에서 `data.js` 뒤에 불러온다. 탄 고르기 창 · 아이템 버튼 · 기록 저장 이름은 자동. 기록 화면 말은 탄 묶음의 `text.records`, 시작 연출은 `ui.js` 의 `INTROS` (없으면 바로 시작) |

탄마다 다른 것은 전부 탄 묶음에 있다 (체력 이름 · 장소 이름 · 결과 문구 · 바닥과 벽 그림 포함). 모든 탄이 같이 쓰는 것: 맵 만드는 방식(방 여러 개 + 복도), 클리어 조건(1층 출구 칸), 주인공 그림, 시작화면.
